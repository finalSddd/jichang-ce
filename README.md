## 三、 怎么用 3 步鉴别“假专线”与超售？

市面上大量月付几元的廉价机场将普通公网中转伪装为“IPLC 专线”。你可以通过以下步骤在本地验证：

1. **晚高峰丢包与抖动（Jitter）测试**：
   在晚上 21:30 打开终端运行 100 次 ping：
   ```bash
   ping -c 100 <节点入口域名或IP>
   ```
   * **真 IPLC 专线**：由于物理专线直连海缆，丢包率恒定为 `0.0%`，抖动通常 `< 3ms`；
   * **假专线（公网伪装）**：晚高峰骨干网拥堵，丢包率骤升至 `3%~15%`，延迟上下波动数十毫秒。
2. **警惕高倍率陷阱**：
   很多机场标称给 500GB，但优质中转或流媒体优化节点被标为 `3x` 甚至 `5x`。如果日常全用 3x 节点，实际 500GB 只能跑 166GB。
3. **坚持月付，拒绝无备案新站大额年付**：
   任何不提供月付试错、强制推行半价“三年付”或“永久套餐”的新生小机场，均蕴含极高的资金跑路风险。

## 四、 常用客户端一键分流与故障转移配置

如果你同时拥有一个主力专线和一个备用按量包，推荐在 **Clash Verge Rev** 或 **Mihomo Party** 的配置中启用 `fallback` 自动故障转移：

```yaml
proxy-groups:
  # 1. 智能自动故障转移组：主力故障时 5 秒内无缝切入备用
  - name: "🚀 故障转移"
    type: fallback
    url: "http://www.gstatic.com/generate_204"
    interval: 300
    proxies:
      - "主力-TAG专线-香港01"
      - "备用-NiceCloud按量-香港"

  # 2. AI 工具独立策略组：固定单一国家出口，防止频繁跳跃封号
  - name: "🤖 AI 工具"
    type: select
    proxies:
      - "主力-TAG专线-美国01"
      - "备用-NiceCloud按量-美国"

rules:
  - DOMAIN-SUFFIX,openai.com,🤖 AI 工具
  - DOMAIN-SUFFIX,chatgpt.com,🤖 AI 工具
  - DOMAIN-SUFFIX,claude.ai,🤖 AI 工具
  - DOMAIN-SUFFIX,anthropic.com,🤖 AI 工具
  - GEOIP,CN,DIRECT
  - MATCH,🚀 故障转移
```
